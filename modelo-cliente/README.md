# Modelo de repositório da implantação (para o cliente)

Quer guardar a sua implantação num repositório **privado** seu (no GitHub ou numa pasta)? Copie esta pasta:

- `respostas.md` — as respostas que você deu à IA (sem senhas).
- `documentos/` — cartão CNPJ e notas antigas que você mandou (guarde em lugar **privado**).
- `manifesto.json` — o manifesto aplicado (a IA atualiza; aplicar de novo não duplica).
- `historico.md` — o que foi feito e quando.

**Nunca** guarde aqui o certificado digital nem senhas.
